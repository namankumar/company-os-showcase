# Source configuration is intentionally not exported

The original workspace uses host-specific source instructions and local cache snapshots. Those can contain credentials, private records, browser state, and company-specific access rules, so they are not part of this export.

Configure your own sources in a private, ignored location appropriate to your agent host. Treat source snapshots as evidence, record their retrieval time, and keep them separate from the durable context and output documents in this repository.
